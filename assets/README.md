# LNMTL Web to Ebook artwork

The app uses a teal rounded-square emblem containing an ivory open book, a central archiving arrow, and a gold bookmark. The original image was generated with the built-in image-generation tool. Its transparency was preserved when making the platform-specific sizes.

- `logo-master.png`: original generated logo master.
- `app-16.png` through `app-1024.png`: PNG icon sizes, including the 64px header logo and 256px window/Linux desktop icon.
- `app.ico`: Windows executable icon, with multiple resolutions.
- `app.icns`: macOS application icon.

Generation prompt:

> Use case: logo-brand. Asset type: desktop application icon master for 'LNMTL Web to Ebook'. Create one polished minimal symbol, no words or letters: an open ivory book with a small downward archiving arrow integrated into the center fold, on a deep forest teal rounded-square tile. A restrained warm gold bookmark accent. Flat crisp graphic design with subtle depth, bold silhouette legible at 32 pixels. Centered square composition, generous transparent margin outside the rounded tile, no mockup, no extra objects, no watermark. Palette fits a warm ivory and dark teal desktop reading app. Transparent background outside icon tile.
